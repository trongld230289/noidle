# Vi Voice Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** VS Code extension: nhấn Ctrl+Alt+Space (AutoHotkey map từ RCtrl+RAlt), nói tiếng Việt, nhấn lần nữa, chữ được chèn vào terminal / Copilot Chat / editor đang focus.

**Architecture:** Extension host giữ state và status bar; một WebviewPanel thu mic bằng MediaRecorder và trả audio base64 về host; host gửi audio lên Groq whisper-large-v3 rồi chèn text theo đích đã chốt lúc bắt đầu ghi (terminal → `sendText`, chat/editor → lệnh `type`, fallback clipboard).

**Tech Stack:** TypeScript, VS Code Extension API (^1.100), esbuild bundle, vitest, Groq OpenAI-compatible audio API, AutoHotkey v2, @vscode/vsce.

**Spec:** `docs/superpowers/specs/2026-09-10-vi-voice-design.md`

- [ ] **Step 2: Viết src/recorder.ts**

```ts
import * as vscode from 'vscode';
import * as fs from 'fs';
import * as path from 'path';
import * as crypto from 'crypto';

type WebviewMsg =
  | { type: 'started' }
  | { type: 'audio'; base64: string }
  | { type: 'error'; code: 'mic-denied' | 'mic-error'; message: string };

type Waiter = { resolve: (m: WebviewMsg) => void; reject: (e: Error) => void; timer: NodeJS.Timeout };

const WAIT_MS = 10_000;

export class Recorder implements vscode.Disposable {
  private panel: vscode.WebviewPanel | undefined;
  private waiters = new Map<'started' | 'audio', Waiter>();
  private _recording = false;

  constructor(private readonly ctx: vscode.ExtensionContext) {}

  get recording(): boolean {
    return this._recording;
  }

  async start(): Promise<void> {
    const panel = this.ensurePanel();
    const started = this.wait('started');
    void panel.webview.postMessage({ type: 'start' });
    await started;
    this._recording = true;
  }

  async stop(): Promise<Uint8Array> {
    if (!this.panel || !this._recording) throw new Error('Chưa bắt đầu ghi');
    const audio = this.wait('audio');
    void this.panel.webview.postMessage({ type: 'stop' });
    const msg = await audio;
    this._recording = false;
    if (msg.type !== 'audio') throw new Error('Webview trả sai message');
    return new Uint8Array(Buffer.from(msg.base64, 'base64'));
  }

  dispose(): void {
    this.panel?.dispose();
  }

  private ensurePanel(): vscode.WebviewPanel {
    if (this.panel) return this.panel;
    const panel = vscode.window.createWebviewPanel(
      'viVoice.recorder',
      'Vi Voice',
      { viewColumn: vscode.ViewColumn.Beside, preserveFocus: true },
      { enableScripts: true, retainContextWhenHidden: true },
    );
    const nonce = crypto.randomBytes(16).toString('hex');
    const htmlPath = path.join(this.ctx.extensionPath, 'media', 'recorder.html');
    panel.webview.html = fs.readFileSync(htmlPath, 'utf8').replace(/{{nonce}}/g, nonce);
    panel.webview.onDidReceiveMessage((msg: WebviewMsg) => this.onMessage(msg));
    panel.onDidDispose(() => {
      this.panel = undefined;
      this._recording = false;
      for (const [, w] of this.waiters) {
        clearTimeout(w.timer);
        w.reject(new Error('Tab Vi Voice đã bị đóng'));
      }
      this.waiters.clear();
    });
    this.panel = panel;
    return panel;
  }

  private onMessage(msg: WebviewMsg): void {
    if (msg.type === 'error') {
      const key = this.waiters.has('started') ? 'started' : 'audio';
      const w = this.waiters.get(key);
      if (!w) return;
      this.waiters.delete(key);
      clearTimeout(w.timer);
      const text =
        msg.code === 'mic-denied'
          ? 'Mic bị từ chối. Cho phép microphone cho VS Code trong Windows Settings > Privacy > Microphone rồi thử lại.'
          : `Không mở được mic: ${msg.message}`;
      w.reject(new Error(text));
      return;
    }
    const w = this.waiters.get(msg.type);
    if (w) {
      this.waiters.delete(msg.type);
      clearTimeout(w.timer);
      w.resolve(msg);
    }
  }

  private wait(key: 'started' | 'audio'): Promise<WebviewMsg> {
    return new Promise((resolve, reject) => {
      const timer = setTimeout(() => {
        this.waiters.delete(key);
        reject(new Error(`Webview không phản hồi (${key})`));
      }, WAIT_MS);
      this.waiters.set(key, { resolve, reject, timer });
    });
  }
}
```

```ts
export type TranscribeErrorKind = 'auth' | 'rate' | 'network' | 'server';

export class TranscribeError extends Error {
  constructor(public readonly kind: TranscribeErrorKind, message: string) {
    super(message);
    this.name = 'TranscribeError';
  }
}

export interface TranscribeOptions {
  apiKey: string;
  fetchFn?: typeof fetch;
  timeoutMs?: number;
}

const GROQ_URL = 'https://api.groq.com/openai/v1/audio/transcriptions';
const MODEL = 'whisper-large-v3';
// Gợi ý ngữ cảnh để Whisper giữ nguyên thuật ngữ lập trình tiếng Anh.
const PROMPT =
  'Tôi cần refactor function claimNext, rồi commit và tạo pull request. ' +
  'Component này dùng React hook, gọi API endpoint trả về JSON, viết unit test bằng vitest.';

export function postProcess(text: string): string {
  return text.trim().replace(/\.$/u, '');
}

export async function transcribe(audio: Uint8Array, opts: TranscribeOptions): Promise<string> {
  const fetchFn = opts.fetchFn ?? fetch;
  const form = new FormData();
  form.append('file', new Blob([audio as BlobPart], { type: 'audio/webm' }), 'audio.webm');
  form.append('model', MODEL);
  form.append('language', 'vi');
  form.append('response_format', 'json');
  form.append('prompt', PROMPT);

  const controller = new AbortController();
  const timer = setTimeout(() => controller.abort(), opts.timeoutMs ?? 30_000);
  let res: Response;
  try {
    res = await fetchFn(GROQ_URL, {
      method: 'POST',
      headers: { Authorization: `Bearer ${opts.apiKey}` },
      body: form,
      signal: controller.signal,
    });
  } catch (err) {
    throw new TranscribeError('network', `Không gọi được Groq: ${(err as Error).message}`);
  } finally {
    clearTimeout(timer);
  }

  if (res.status === 401) throw new TranscribeError('auth', 'Groq API key không hợp lệ');
  if (res.status === 429) throw new TranscribeError('rate', 'Groq đang giới hạn, thử lại sau vài giây');
  if (!res.ok) throw new TranscribeError('server', `Groq trả lỗi HTTP ${res.status}`);

  const data = (await res.json()) as { text?: string };
  return postProcess(data.text ?? '');
}
```

```ts
export type Target = 'terminal' | 'chat' | 'editor' | 'clipboard';

export interface InjectorApi {
  activeTerminal(): { sendText(text: string, addNewLine?: boolean): void } | undefined;
  executeCommand(command: string, ...args: unknown[]): Thenable<unknown>;
  writeClipboard(text: string): Thenable<void>;
}

/** Chèn text vào đích; nếu đích không dùng được thì copy vào clipboard. Trả về đích thực sự đã dùng. */
export async function inject(target: Target, text: string, api: InjectorApi): Promise<Target> {
  if (!text) return target;
  try {
    if (target === 'terminal') {
      const terminal = api.activeTerminal();
      if (!terminal) throw new Error('Không có terminal đang mở');
      terminal.sendText(text, false);
      return 'terminal';
    }
    if (target === 'chat' || target === 'editor') {
      await api.executeCommand('type', { text });
      return target;
    }
  } catch {
    // rơi xuống clipboard
  }
  await api.writeClipboard(text);
  return 'clipboard';
}
```

```ts
import * as vscode from 'vscode';
import { StatusBar } from './status';
import { Recorder } from './recorder';
import { transcribe, TranscribeError } from './transcriber';
import { inject, InjectorApi, Target } from './injector';

const SECRET_KEY = 'viVoice.groqApiKey';
const MAX_RECORD_MS = 120_000;
const MIN_RECORD_MS = 500;

export function activate(ctx: vscode.ExtensionContext): void {
  const status = new StatusBar();
  const recorder = new Recorder(ctx);
  const api: InjectorApi = {
    activeTerminal: () => vscode.window.activeTerminal,
    executeCommand: (command, ...args) => vscode.commands.executeCommand(command, ...args),
    writeClipboard: (text) => vscode.env.clipboard.writeText(text),
  };

  let target: Target = 'clipboard';
  let startedAt = 0;
  let busy = false;
  let lastAudio: Uint8Array | undefined;
  let maxTimer: NodeJS.Timeout | undefined;

  async function setApiKey(): Promise<string | undefined> {
    const value = await vscode.window.showInputBox({
      prompt: 'Groq API key (bắt đầu bằng gsk_). Lấy miễn phí tại console.groq.com/keys',
      password: true,
      ignoreFocusOut: true,
    });
    const key = value?.trim();
    if (key) await ctx.secrets.store(SECRET_KEY, key);
    return key || undefined;
  }

  async function getApiKey(): Promise<string | undefined> {
    return (await ctx.secrets.get(SECRET_KEY)) ?? setApiKey();
  }

  async function deliver(audio: Uint8Array): Promise<void> {
    const apiKey = await getApiKey();
    if (!apiKey) return;
    status.set('transcribing');
    try {
      const text = await transcribe(audio, { apiKey });
      lastAudio = undefined;
      if (!text) {
        void vscode.window.showWarningMessage('Vi Voice: không nghe được gì');
        return;
      }
      const used = await inject(target, text, api);
      if (used === 'clipboard') {
        void vscode.window.showInformationMessage(`Vi Voice: đã copy vào clipboard: "${text}"`);
      }
    } catch (err) {
      lastAudio = audio;
      if (err instanceof TranscribeError && err.kind === 'auth') {
        const pick = await vscode.window.showErrorMessage(`Vi Voice: ${err.message}`, 'Nhập lại key');
        if (pick) await setApiKey();
      } else {
        const message = err instanceof Error ? err.message : String(err);
        const pick = await vscode.window.showErrorMessage(`Vi Voice: ${message}`, 'Gửi lại');
        if (pick) void vscode.commands.executeCommand('viVoice.retry');
      }
    } finally {
      status.set('idle');
    }
  }

  async function toggle(args?: { target?: Target }): Promise<void> {
    if (busy) return;
    busy = true;
    try {
      if (!recorder.recording) {
        if (!(await getApiKey())) return;
        target = args?.target ?? 'clipboard';
        await recorder.start();
        startedAt = Date.now();
        status.set('recording');
        maxTimer = setTimeout(() => void vscode.commands.executeCommand('viVoice.toggle'), MAX_RECORD_MS);
        return;
      }
      clearTimeout(maxTimer);
      const audio = await recorder.stop();
      if (Date.now() - startedAt < MIN_RECORD_MS) {
        status.set('idle');
        return;
      }
      await deliver(audio);
    } catch (err) {
      status.set('idle');
      void vscode.window.showErrorMessage(`Vi Voice: ${(err as Error).message}`);
    } finally {
      busy = false;
    }
  }

  async function retry(): Promise<void> {
    if (!lastAudio) {
      void vscode.window.showInformationMessage('Vi Voice: không có audio để gửi lại');
      return;
    }
    await deliver(lastAudio);
  }

  ctx.subscriptions.push(
    status,
    recorder,
    vscode.commands.registerCommand('viVoice.toggle', toggle),
    vscode.commands.registerCommand('viVoice.setApiKey', setApiKey),
    vscode.commands.registerCommand('viVoice.retry', retry),
  );
}

export function deactivate(): void {}
```

# Vi Voice

Gõ tiếng Việt bằng giọng nói vào terminal (Claude Code), Copilot Chat và editor trong VS Code. Dùng Groq whisper-large-v3 gói miễn phí.

## Cài

1. `npm install && npm run package` → tạo `vi-voice-0.1.0.vsix`
2. `code --install-extension vi-voice-0.1.0.vsix`
3. Lấy API key miễn phí tại https://console.groq.com/keys
4. Trong VS Code: `Ctrl+Shift+P` → `Vi Voice: Set Groq API Key`

## Dùng

- Click vào terminal / ô chat / editor.
- Nhấn `Ctrl+Alt+Space`, nói, nhấn lại. Chữ được chèn vào chỗ vừa click. Bạn tự nhấn Enter.
- Tab "Vi Voice" mở bên cạnh là nơi giữ quyền mic, cứ để đó (kéo vào nhóm tab khác cũng được).
- Lỗi mạng: `Vi Voice: Gửi lại audio cuối`.

## Phím Ctrl phải + Alt phải

1. Cài AutoHotkey v2: `winget install AutoHotkey.AutoHotkey`
2. Chạy `hotkey/vi-voice.ahk` (double-click). Muốn tự chạy khi khởi động: tạo shortcut vào `shell:startup`.
3. Trong VS Code, giữ Ctrl phải rồi nhấn Alt phải.

## Phát triển

- `npm run watch` + F5 trong VS Code để mở Extension Development Host.
- `npm test` chạy unit test (vitest).
