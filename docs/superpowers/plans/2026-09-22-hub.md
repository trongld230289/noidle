# Hub Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Trang web LAN (điện thoại xem được) gom trạng thái mọi phiên Claude Code và ra lệnh xếp hàng, approve, trả lời câu hỏi; project `hub/` độc lập với extension.

**Architecture:** Hook CLI (`hub.js hook <event>`) ghi hộp thư JSON mỗi phiên vào `%TEMP%\vi-voice-hub\inbox`; tiến trình nền `hub.js serve` (HTTP thuần Node + SSE) phục vụ trang và ghi file decision/queue; hook Stop đọc queue và chặn dừng kèm lệnh; hook PermissionRequest/AskUserQuestion chờ decision khi có người xem.

**Tech Stack:** Node 20+, TypeScript, esbuild (bundle một file `dist/hub.js`), vitest. Không dependency runtime.

**Spec:** `docs/superpowers/specs/2026-09-22-hub-design.md`

## Global Constraints

- Không import bất kỳ file nào từ `../src` (extension). Không dùng thư mục `vi-voice-tts`.
- Thư mục tạm: `path.join(os.tmpdir(), 'vi-voice-hub')`; con: `inbox/`, `hub.lock`, `hub.log`.
- Cấu hình: `~/.vi-voice/hub.json` `{ enabled, port: 4319, lan: false, token, waitSec: 90, lang: 'vi' }`.
- Mọi đường dẫn HTTP dưới `/t/<token>/`; sai token → 404 body rỗng.
- Hook stdout chỉ được in JSON hợp lệ hoặc không in gì.
- Dấu nhận diện hook trong settings: lệnh chứa `vi-voice-hub`.
- Test chạy bằng `npx vitest run` trong `hub/`; test hook chạy bundle thật với env `TEMP/TMP/TMPDIR` trỏ thư mục tạm riêng và `VI_VOICE_HUB_HOME` trỏ thư mục config riêng, `VI_VOICE_HUB_NO_SERVE=1` để hook không tách server trong test.

### Task 4: hook events → inbox (chưa chờ)

**Files:** `hub/src/hook.ts` (xử lý stdin JSON theo event, thuần: nhận `input`, `dir`, `now`), `hub/src/main.ts` (CLI), `hub/test/hook.test.ts` (chạy bundle).

```ts
export interface HookInput { hook_event_name?: string; session_id?: string; cwd?: string; prompt?: string; agent_id?: string; transcript_path?: string; stop_hook_active?: boolean; tool_name?: string; tool_input?: any; notification_type?: string }
export async function handleHook(event: string, input: HookInput, opts: { dir: string; cfg: HubConfig; now?: () => number; wait?: (session: string) => Promise<Decision | undefined> }): Promise<object | undefined>  // trả object để in JSON, undefined = không in
```
- UserPromptSubmit: agent_id → undefined, không ghi. Else updateInbox working, lastPrompt 200 ký tự, clearPending.
- Stop: đọc transcript_path → lastSpoken; state done. stop_hook_active và không có flag 'ours' → không ghi (lượt do hook khác chặn). Có queue → trả `{decision:'block', reason}`, setFlag ours, giữ state working, clearQueued.
- PermissionRequest: pending approve {toolName, summary, dangerous}; state waiting_approve.
- PreToolUse (tool AskUserQuestion): pending question từ tool_input.questions[0] (question, options[].label, multiSelect); waiting_answer.
- Notification elicitation_dialog: waiting_answer, question = message.
- main.ts: `hook <event>` đọc stdin, loadConfig; enabled false → thoát 0 không làm gì; gọi handleHook; in JSON nếu có; sau đó `ensureServe()` trừ khi env `VI_VOICE_HUB_NO_SERVE`.
- esbuild: `hub/scripts/build.mjs` hoặc script npm: `esbuild src/main.ts --bundle --platform=node --target=node20 --format=cjs --outfile=dist/hub.js`.

### Task 5: server + trang

**Files:** `hub/src/hub.ts`, `hub/src/page.ts`, `hub/test/hub.test.ts`.

```ts
export interface HubOptions { dir: string; token: string; port: number; host: string; lang: 'vi'|'en'; version: string; onClient?: (at: number) => void; log?: (m: string) => void }
export function startHub(o: HubOptions): Promise<{ port: number; close(): Promise<void>; lastClientAt(): number }>
```
Routes dưới `/t/<token>`: `/` HTML; `/api/state`; `/api/events` SSE (fs.watch dir, debounce 200ms, gửi `data: <json state>`); `/api/send` POST {session,text} → writeQueue + updateInbox queued; `/api/decide` POST → chỉ khi waiting; allow bị chặn nếu pending.dangerous → 409; `/api/ping`. Sai token → 404. Body JSON tối đa 64KB.
Page: vanilla, fetch state, EventSource, thẻ theo spec, Web Speech (Tự đọc, nghe lại, dừng), nhãn vi/en.

### Task 6: serve + lock + CLI open/status

**Files:** `hub/src/main.ts`, `hub/src/lock.ts`.
- `serve`: ensureConfig, startHub(host = lan ? '0.0.0.0' : '127.0.0.1'), thử port..port+5; ghi `hub.lock` {pid, port, at, lastClientAt} mỗi 60s; thoát sau 4h không request và inbox mtime không đổi.
- `ensureServe()`: đọc lock; pid sống → return; else spawn detached `process.execPath [script, 'serve']`, stdio ignore, unref.
- `open`: in URL(s): `http://127.0.0.1:<port>/t/<token>/` và với lan, mỗi IPv4 non-internal.
- `status`: in config, lock, số phiên.
- `install [--lan] [--port N]`: ensureConfig (enabled true), applyHooks vào `~/.claude/settings.json` (backup `.bak`), in URL. `uninstall`: applyHooks enabled false, config enabled false.

### Task 7: chờ decision trong hook

Trong main.ts, `wait` cho PermissionRequest/PreToolUse/Notification: đọc lock.lastClientAt; nếu trong 60s → poll takeDecision mỗi 300ms tối đa cfg.waitSec. handleHook nhận decision: PermissionRequest → `{hookSpecificOutput:{hookEventName:'PermissionRequest', decision:{behavior, message?}}}` (allow với dangerous → bỏ qua); AskUserQuestion → `{hookSpecificOutput:{hookEventName:'PreToolUse', permissionDecision:'deny', permissionDecisionReason:'Người dùng đã trả lời qua hub: ...'}}`; sau quyết định updateInbox working clearPending. Test: decision ghi sẵn + lock có lastClientAt mới → output đúng; không lock → không chờ (<1s).
